# Spookology 🎃

A small, static Halloween website starter — a landing page with a live countdown to October 31st.

## Features

- Live countdown timer to Halloween
- Simple, spooky dark theme
- No build step — just open `index.html` in a browser

## Getting Started

Clone the repo and open `index.html` directly in your browser, or serve the folder locally:

```bash
npx serve .
```

## Project Structure

```
.

├── css/
```
